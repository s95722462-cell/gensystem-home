03

설비 소프트웨어

현장에 맞춘 자체 개발 도구.

  • 결선도·전선 목록 자동 생성
  • 휴대폰 설비 모니터·원격 조작
  • 카메라 비전 감시 (보조 기능)
  • 서보 튜닝 도우미
  • 지점 업무용 ERP (데스크톱 앱)

현장을 아는 무역, 무역을 아는 기술

GEN SYSTEM은 자동화 설비 유지보수 실무와 무역 회사에서 쌓은 글로벌 소싱·수출입 경험을 바탕으로 출발했습니다. 단순 판매가 아니라, 설비에 맞는 부품과 그 부품을 움직이는 프로그램까지 함께 제안합니다.

기술 사례

직접 만들고, 시험 장비에서 확인했습니다

각 사례는 과제 → 만든 것 → 결과 순서로 정리했습니다. 화면과 도면은 모두 자체 시험 장비·가상 설비 자료입니다.

Wiring Studio

결선도 자동 생성

과제
공급사마다 BOM 형식이 달라, 도면과 전선 목록을 매번 손으로 다시 그려야 했습니다.
만든 것
어떤 공급사 BOM이든 표준 BOM으로 정리한 뒤, 규칙에 따라 주회로·시스템 구성·서보·IO(32점 표) 도면과 전선 목록, 마킹 CSV를 만들고 DXF·PDF로 출력합니다.
결과
규칙 기반이라 설비가 바뀌어도 같은 방식으로 동작합니다. 서로 다른 설비 데이터로 시험했고, 가상 설비 1대분 도면 26장을 한 번에 출력했습니다.

Remote Monitor

휴대폰 설비 모니터 · 원격 조작

과제
설비 상태를 보려면 현장에 가야 했고, 원격 버튼은 안전이 걱정이었습니다.
만든 것
PLC 실시간 데이터를 휴대폰에서 확인(Firebase). 원격 버튼에는 겹겹의 안전 설계를 넣었습니다.
  • 현장 허용 HMI의 ‘원격 허용’ 스위치가 켜져 있을 때만 동작
  • 3초 감시 PLC 래더가 하트비트를 감시, 끊기면 원격 명령 차단
  • 지연 거절 늦게 도착한 명령·모르는 명령은 실행하지 않음
  • 계정 제한 허용된 Google 계정 하나만 접속

결과 조건이 맞지 않으면 PLC가 실행하지 않고, 거절 이유를 화면에 남깁니다.

Vision Guard

카메라 비전 감시

과제
작업 구역에 손이나 물체가 들어오면 서보를 빨리 멈추는 보조 수단이 필요했습니다.
만든 것
USB 카메라로 감시 구역 침입을 감지하고, PLC를 거쳐 서보를 정지시킵니다.
결과
시험 장비에서 감지부터 정지까지 약 0.4초 (이송 속도 9000 mm/min 조건)로 측정했습니다.

보조 기능이며 안전장치(안전 인증 장치)가 아닙니다. 라이트 커튼·안전 릴레이 등 인증된 안전장치를 대신하지 않습니다.

Servo Tuning

서보 튜닝 도우미

MR Configurator2를 자동으로 조작해 원터치 튜닝, 파라미터 백업(되돌리기용), A4 보고서를 한 번에 처리합니다. 인터넷이 없는 현장 노트북에서도 실행됩니다.

GOT HMI

다국어 GOT 화면

한국어·English·Tiếng Việt를 버튼 하나로 전환. 운전·JOG·단계 운전·알람 화면을 같은 구조로 만듭니다.

Serial

온도 조절기 통신

E5CC 온도 조절기를 PLC 시리얼 통신 모듈로 연결해 현재값·설정값을 읽고 쓰고, 센서·통신 이상을 화면에 표시합니다.

Desktop App

지점 업무 ERP

지점 업무를 관리하는 데스크톱 ERP 프로그램을 개발했습니다. 현장 PC에 맞춘 가벼운 구성입니다.

2차전지 · 제조 라인 대응

라인이 늘어나는 속도에 맞춰, 데이터·문서·부품을 준비합니다

공정과 설비가 많은 2차전지·제조 현장에서 반복되는 일 — 설비 데이터 확인, 도면 정리, 부품 조달 — 을 작은 팀의 속도로 처리합니다.

설비 데이터 수집·원격 모니터링

PLC 데이터를 Ethernet(MC 프로토콜)으로 모아 상태·알람·추이를 PC와 휴대폰에서 확인합니다.

문서·도면 표준화

공급사마다 다른 BOM을 하나의 형식으로 정리하고, 도면·전선 목록·마킹 자료와 다국어 HMI를 같은 규칙으로 만듭니다.

빠른 부품 조달·단종 대응

미쓰비시 계열 부품을 국내외에서 빠르게 찾고, 단종 품목은 대체 모델과 배선·파라미터 호환까지 확인해 제안합니다.

보안 원칙

  • 설비 데이터는 기본적으로 현장 안에 둡니다
  • 고객 자료를 외부 서비스에 올리지 않습니다
  • 외부 연결이 필요하면 범위·방식을 먼저 협의합니다
  • 접속은 허용된 계정만, 원격 조작은 현장 허용 시에만
